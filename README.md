
# Sistema de riego automático con Arduino 🌱

Proyecto de RubalErikCreativo para automatizar el riego de plantas mediante Arduino.

## Descripción
Este proyecto utiliza un sensor de humedad del suelo para controlar el riego de una planta mediante una bomba de agua.

## Componentes principales
- Arduino
- Sensor capacitivo de humedad del suelo
- Bomba de agua sumergible
- Transistor de control
- Fuente de alimentación adecuada
- Cables de conexión

## Código fuente
Archivo: `riego_de_plantas_atm.ino`

Para descargar el proyecto completo, utiliza el botón verde **Code → Download ZIP** de GitHub.

## Instrucciones
1. Descarga el código.
2. Abre el archivo `.ino` en Arduino IDE.
3. Revisa las conexiones y los pines definidos en el código.
4. Instala las bibliotecas necesarias, si corresponde.
5. Carga el programa en tu placa Arduino.

**Importante:** verifica el circuito y la alimentación de la bomba antes de energizarlo.
